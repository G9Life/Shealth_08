## 1. 개요

### 1.1 작업 목적

삼성 헬스 도메인의 **BMI 4단계 분류**(저체중 · 정상 · 과체중 · 비만)를 `SHealth::classifyBmi` 단위 테스트로 검증한다. `shealth.dat` 실측 샘플과 임계값 **18.5 / 23.0 / 25.0** 경계를 포함하며, Given-When-Then 주석과 `EXPECT_EQ` / `ASSERT_EQ`로 기대 `BmiCategory`를 고정한다.

| 요구사항 | 충족 |
|----------|------|
| 4구간(저체중/정상/과체중/비만) 각각 검증 | ✅ 대표 id + 경계 케이스 |
| `TEST_F` 최소 5개 (분류 중심) | ✅ 6개 (`SHealthBmiCalculationFixture`) |
| `EXPECT_EQ` / `ASSERT_EQ` | ✅ `BmiCategory` enum + milli-BMI |
| `shealth.dat` 기반 경계값 | ✅ 8 id + 이론 임계 |
| Given-When-Then 주석 | ✅ |
| `cmake --build build && ctest` Green | ✅ 분류 관련 CTest #1–#9 Passed |

### 1.3 분류 기준 (`bmi.png` · README)

![BMI](../bmi.png)

| 구간 (한글) | 영문 enum | README 조건 | `classifyBmi` 구현 |
|-------------|-----------|-------------|-------------------|
| 저체중 | `Underweight` | BMI ≤ 18.5 | `bmi <= 18.5` |
| 정상 | `Normal` | 18.5 초과 ~ 23 미만 | `bmi < 23.0` |
| 과체중 | `Overweight` | 23 이상 ~ 25 미만 | `bmi < 25.0` |
| 비만 | `Obesity` | BMI ≥ 25 | 그 외 |

레거시·출력용 정수 코드 (`SHealth.h`):

| `BmiCategory` | 코드 |
|---------------|------|
| `Underweight` | 100 |
| `Normal` | 200 |
| `Overweight` | 300 |
| `Obesity` | 400 |

구현 (`SHealth.cpp`):

```cpp
SHealth::BmiCategory SHealth::classifyBmi(double bmi) {
    if (bmi <= kUnderweightMaxBmi) { return BmiCategory::Underweight; }  // 18.5
    if (bmi < kNormalMaxBmi)       { return BmiCategory::Normal; }       // 23.0
    if (bmi < kOverweightMaxBmi)   { return BmiCategory::Overweight; }   // 25.0
    return BmiCategory::Obesity;
}
```

## 5. Given-When-Then 예시

### 5.1 구간 대표 — 정상

```cpp
TEST_F(SHealthBmiCalculationFixture, GivenShealth93711NormalRow_WhenComputeBmi_ThenMilliAndCategoryMatch) {
    // Given: shealth.dat id=93711 (62.1 kg, 170.6 cm) — normal-range sample
    const double weightKg = kShealth93711WeightKg;
    const double heightCm = kShealth93711HeightCm;

    // When: BMI is computed and classified
    const SHealth::BmiCategory category = SHealth::classifyBmi(SHealth::computeBmi(weightKg, heightCm));

    // Then: category is Normal
    EXPECT_EQ(category, SHealth::BmiCategory::Normal);
}
```

### 5.2 경계 일괄 — 4구간

```cpp
// Given: exact BMI at classification thresholds (height = 100 cm)
// When / Then:
EXPECT_EQ(SHealth::classifyBmi(SHealth::computeBmi(18.5, 100.0)), SHealth::BmiCategory::Underweight);
EXPECT_EQ(SHealth::classifyBmi(SHealth::computeBmi(22.9, 100.0)), SHealth::BmiCategory::Normal);
EXPECT_EQ(SHealth::classifyBmi(SHealth::computeBmi(24.9, 100.0)), SHealth::BmiCategory::Overweight);
EXPECT_EQ(SHealth::classifyBmi(SHealth::computeBmi(25.0, 100.0)), SHealth::BmiCategory::Obesity);
```
