`BmiCalculator::classifyBmi` 기준:

- **저체중**: BMI ≤ 18.5  
- **정상**: **18.5 < BMI < 23.0**  
- **과체중**: 23.0 ≤ BMI < 25.0  
- **비만**: BMI ≥ 25.0  

`classifyBmi(record.bmi) == BmiCategory::Normal`과 동일한 조건입니다.

## 구현 방식

```74:89:c:\DEV\Shealth_08\src\main\cpp\SHealth.cpp
std::vector<SHealth::HealthRecord> SHealth::getNormalBmiRecords() const {
    if (records_.empty()) {
        return {};
    }

    std::vector<HealthRecord> normalRecords;
    normalRecords.reserve(records_.size());

    for (const HealthRecord& record : records_) {
        if (classifyBmi(record.bmi) == BmiCategory::Normal) {
            normalRecords.push_back(record);
        }
    }

    return normalRecords;
}
```

- `records_.empty()`이면 미로드·로드 실패 모두 빈 벡터 반환  
- 선형 스캔 + `reserve`로 불필요한 재할당 최소화  
- `HealthRecord`(`id`, `age`, `weightKg`, `heightCm`, `bmi`) 그대로 반환
