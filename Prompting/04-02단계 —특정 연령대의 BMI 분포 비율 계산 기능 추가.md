`getDistributionForAgeDecade` API와 테스트를 추가합니다.


## 변경 요약

`SHealth`에 특정 연령대의 BMI 4개 범주 비율을 한 번에 반환하는 `getDistributionForAgeDecade(int ageDecade)`를 추가했습니다. 기존 `distributionsByDecade_` 맵을 그대로 조회하며, `getCategoryPercent()` 동작은 변경하지 않았습니다.

## 추가된 public API

```cpp
AgeDecadeDistribution getDistributionForAgeDecade(int ageDecade) const;
```

사용 예:

```cpp
SHealth::AgeDecadeDistribution distribution =
    analyzer.getDistributionForAgeDecade(50);
// distribution.underweightPercent, normalPercent, overweightPercent, obesityPercent
```

## 구현 방식 설명

- `distributionsByDecade_`에서 `ageDecade` 키를 찾아 있으면 해당 `AgeDecadeDistribution`을 복사해 반환합니다.
- 맵에 없으면(미로드, 잘못된 연령대 등) 기본값 `AgeDecadeDistribution{}`를 반환해 네 필드가 모두 `0.0`입니다.
- `loadAndCalculate()` 시 `BmiDistributionAnalyzer::computeDistributionsByAgeDecade()`가 이미 맵을 채우므로, 추가 계산 없이 캐시된 분포만 읽습니다.
- `getCategoryPercent()`는 기존과 같이 같은 맵 + `percentForCategory()`를 사용하므로, 두 API 결과는 일치합니다.

## 추가한 테스트 케이스

| 테스트 | 검증 내용 |
|--------|-----------|
| `GivenUnloadedAnalyzer_WhenGetDistributionForAgeDecade_ThenAllPercentsAreZero` | 미로드 시 전 필드 0.0 |
| `GivenLoadedShealthDat_WhenGetDistributionForAgeDecade50_ThenMatchesCategoryPercentApi` | shealth.dat 50대 분포가 `getCategoryPercent`와 일치, 합 100% |
| `GivenLoadedShealthDat_WhenGetDistributionForInvalidAgeDecade_ThenAllPercentsAreZero` | 잘못된 연령대(25) → 전 필드 0.0 |
| `GivenThreeMemberFixtureWithOneZeroWeight_...` (기존 테스트 확장) | `getDistributionForAgeDecade(50)` → 33/33/33/0 |

## 남은 개선 후보

- `SHealthBMI.cpp`의 `printAgeDecadeDistribution`을 `getDistributionForAgeDecade`로 단순화해 4회 `getCategoryPercent` 호출 제거
