`SHealth`가 담당하던 6가지 책임(CSV 파싱·검증, 체중 보정, BMI 계산·분류, 나이대 정책, 분포 통계, Facade API)을 **7개 클래스**로 분리했습니다. 기존 `SHealth` public API와 Google Test 21건은 변경 없이 통과합니다.

## 핵심 코드 변경 설명

**1. 모델·순수 계산 분리**  
`HealthRecord`, `BmiTypes`, `BmiCalculator`, `AgeDecadePolicy`로 데이터와 도메인 규칙을 독립시켰습니다.

**2. CSV 로딩 분리**  
`HealthRecordCsvReader::loadFromFile` / `isValidRecord` / `resolveDataFilePath`가 파일 I/O 전담.

**3. 체중 보정 분리**  
`WeightImputer::imputeMissingWeights`가 나이대 평균 계산·0kg 대체 담당.

**4. 분포 계산 분리**  
`BmiDistributionAnalyzer`가 BMI 계산 후 나이대별 범주 비율을 `unordered_map`으로 생성.

**5. SHealth Facade 축소**  
`loadAndCalculate`는 4단계 파이프라인만 조율합니다.

```cpp
// SHealth.cpp — Facade 파이프라인
HealthRecordCsvReader::loadFromFile(filename, records_);
WeightImputer::imputeMissingWeights(records_);
BmiDistributionAnalyzer::calculateBmis(records_);
distributionsByDecade_ = BmiDistributionAnalyzer::computeDistributionsByAgeDecade(records_);
```

정적 API(`computeBmi`, `classifyBmi`, `belongsToAgeDecade` 등)는 `SHealth`에서 각 클래스로 위임해 테스트·`SHealthBMI.cpp` 호환을 유지합니다.

## 남은 개선 후보

1. **단위 테스트 확장** — `BmiCalculator`, `WeightImputer` 등을 `SHealth` 없이 직접 검증하는 테스트 추가
2. **`BmiTypes.h` 정리** — `SHealth::kAllBmiCategories` alias 대신 테스트에서 공통 타입 직접 참조 검토
3. **CSV 예외 처리** — `std::stoi`/`stod` 실패 시 현재는 예외 전파; 잘못된 행 skip 정책 명시 가능
4. **`HealthRecordCsvReader::resolveDataFilePath`** — Facade가 아닌 reader 전용 유틸로 두었으나, main/테스트는 계속 `SHealth::` 경유
5. **빌드 산출물 `.gitignore`** — `build/` 디렉터리 미추적 권장

리팩토링 전후 핵심 차이: **단일 God 클래스 → 책임별 협력 객체 + SHealth Facade**. 동작은 동일하고, 각 파일이 한 가지 이유로만 변경되도록 구조가 나뉘었습니다.
