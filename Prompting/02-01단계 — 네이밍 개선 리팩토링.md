코드 스멜(전역 배열, 매직 넘버, 중복 if-else)을 제거하고 모던 C++ 스타일로 리팩토링합니다. 제약 조건(age > 0, id/height ≥ 0) 검증도 추가합니다.


테스트에서 사용하는 헬퍼를 public static으로 노출합니다.


테스트가 `build` 디렉터리에서 실행되어 데이터 파일을 찾지 못합니다. CMake에서 작업 디렉터리를 프로젝트 루트로 설정합니다.


1차 리팩토링(네이밍·하드코드 제거·함수 추출·중복 제거)을 프로젝트 전체에 적용했고, 빌드·실행·테스트까지 확인했습니다.

## 실행한 단계

| 단계 | 내용 |
|------|------|
| 1 | 코드 스멜 분석 — C 배열, 매직 넘버(100/200/300/400), 연령대별 24개 멤버 변수, 거대 `if-else` |
| 2 | **네이밍** — `calculateBmi` → `loadAndCalculate`, `split` → `splitCsvLine`, `count` → `records_` 등 |
| 3 | **하드코드 제거** — BMI 기준·연령대 범위를 `constexpr` 상수·`BmiCategory` enum으로 정리 |
| 4 | **함수 추출** — 로드 / 체중 보정 / BMI 계산 / 연령대 통계를 각각 분리 |
| 5 | **중복 제거** — `underweight20`…`obesity70` → `unordered_map<int, AgeGroupDistribution>` |
| 6 | **검증 추가** — `age > 0`, `id >= 0`, `height >= 0` 미충족 레코드 스킵 |
| 7 | 테스트 정리 — `FAIL()` 제거, 분류·검증·로드 스모크 테스트 추가 |

## 주요 변경

**데이터 모델**
- `HealthRecord`, `AgeGroupDistribution` 구조체 도입
- 고정 크기 C 배열 → `std::vector<HealthRecord>`

**BMI 분류 (README 기준, 버그 수정)**
- 비만: 기존 `> 25` → **`>= 25`** (`25이상 비만`)

**API (하위 호환)**
- `getBmiRatio(ageDecade, 100|200|300|400)` 시그니처 유지 → `SHealthBMI.cpp` 출력 형식 동일

**실행 결과** (프로젝트 루트에서 `./build/SHealthBMI.exe`):

```
20 - underweight = 3.511053, normal = 23.797139, ...
...
70 - underweight = 0.529101, normal = 12.345679, ...
```

**테스트**: 3/3 통과 (`ctest`)

## Before → After 요약

```cpp
// Before: 24개 멤버 + 거대 if-else
double underweight20, normalweight20, ...;
if (ageClass == 20 && type == 100) return underweight20;

// After: map + enum + 단일 switch
enum class BmiCategory { Underweight = 100, Normal = 200, ... };
std::unordered_map<int, AgeGroupDistribution> distributionsByDecade_;
```
