CMakeLists 변경으로 재구성이 실패했습니다. 이미 있는 googletest 소스를 쓰도록 CMake를 수정합니다.


리팩토링을 완료했습니다. 기존 전역 배열·연령대별 24개 변수·`main`의 매직 넘버를 제거하고, 모던 C++(STL, enum, RAII) 구조로 정리했습니다.

## Before → After

| 항목 | Before | After |
|------|--------|-------|
| 데이터 저장 | `ages[10000]`, `weights[]` 등 고정 배열 | `std::vector<HealthRecord>` |
| 통계 저장 | `underweight20` ~ `obesity70` (24개 멤버) | `unordered_map<int, AgeDecadeDistribution>` |
| `main` | `100/200/300/400`, `20~70` 하드코드, 6회 `printf` 중복 | `SHealth::kMinAgeDecade` 등 상수 + 루프 1회 |
| 연령대 | `(age/10)*10` (19세 → 10대 등 오차) | `belongsToAgeDecade()` — `20≤age<30` 원본과 동일 |
| 검증 | 없음 | `isValidRecord()`: `id≥0`, `age>0`, `height≥0` |

## 주요 변경

**`SHealth.h` / `SHealth.cpp`**
- `HealthRecord`, `AgeDecadeDistribution` 구조체로 데이터·통계 캡슐화
- BMI 임계값·연령대 범위를 `constexpr` 상수로 분리
- `classifyBmi()`, `computeBmi()`, `belongsToAgeDecade()` 정적 메서드로 로직 분리
- 체중 0 보정 → `imputeMissingWeightsByAgeDecade()`
- `getCategoryPercent(ageDecade, BmiCategory)` — 기존 `getBmiRatio` 대체 (레거시 `int` 코드도 지원)

**`SHealthBMI.cpp`**
- 전역 변수 제거
- `SHealth::kMinAgeDecade` ~ `kMaxAgeDecade` 상수 사용
- `resolveDataFilePath()`로 `build/`·프로젝트 루트 모두에서 `shealth.dat` 탐색
- CLI 인자: `./SHealthBMI [데이터파일경로]`

**테스트** (`SHealthBMITest.cpp`) — 7개 TC, 전부 통과
- BMI 분류·계산, 입력 검증, 연령대 구간, 데이터 로드, 비율 합 100%, 레거시 category code
