## 정상 BMI 판정 기준

`SHealth::classifyBmi()` → `BmiCalculator::classifyBmi()` 기준:

- **18.5 < BMI < 23.0** → `BmiCategory::Normal`
- 경계: BMI ≤ 18.5는 저체중, BMI ≥ 23.0은 과체중 이상

## 구현 방식

```74:90:c:\DEV\Shealth_08\src\main\cpp\SHealth.cpp
std::vector<SHealth::HealthRecord> SHealth::getNormalBmiRecords() const {
    if (records_.empty()) {
        return {};
    }

    std::vector<HealthRecord> normalRecords;
    normalRecords.reserve(records_.size());

    for (const HealthRecord& record : records_) {
        if (classifyBmi(record.bmi) == BmiCategory::Normal) {
            normalRecords.push_back(record);
        }
    }

    return normalRecords;
}
```

- `records_`를 순회하며 `classifyBmi(record.bmi) == Normal`인 항목만 `push_back` (복사본 반환, 원본 미수정)
- `records_.empty()`이면 빈 `vector` 반환 (미로드 또는 로드 실패)
